# Taxicheck – TAZ Stuttgart

Webapp zur Prüfung von Taxinummern (angeschlossen / nicht angeschlossen) mit digitalem Formular „Taxi-Kontrolle" und passwortgeschütztem Korrekturbereich. By Danis.

Installierbar als App (PWA): Seite in Chrome auf dem Android-Handy öffnen, Menü > „App installieren".

Adresse nach Aktivierung von GitHub Pages: https://danis0953.github.io/taxicheck/
